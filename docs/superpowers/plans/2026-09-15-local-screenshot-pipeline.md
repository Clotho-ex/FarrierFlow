# Local Screenshot Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, local-only six-of-seven screenshot pipeline using the existing DEBUG showcase fixture, AXe, ASC 5.3.2, and isolated Koubou 0.18.1.

**Architecture:** A fail-closed DEBUG launch configuration injects an isolated store, no-op analytics/subscription clients, a fixed clock, and an active or completed fixture stage. A Bash wrapper interprets declarative capture definitions, owns only one dedicated simulator, captures through `asc screenshots run`, composes through `asc screenshots frame` with a scoped pinned Koubou path, and generates an offline review bundle.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, Swift Testing, Bash 3.2, jq, xcodebuild/simctl, AXe 1.8.0, ASC 5.3.2, Koubou 0.18.1.

**Spec:** `docs/growth/local-screenshot-pipeline.md`

## Global Constraints

- Local tool validation only; the wrapper must not install or downgrade tools.
- No App Store Connect, Apple Ads, PostHog, or RevenueCat mutation or upload behavior.
- No `asc screenshots apply`, upload, approve, plan, submit, or release commands.
- Keep global Koubou 0.20.0 untouched; scope Koubou 0.18.1 to framing.
- Screenshot 5 remains blocked until approved original hoof-photo assets exist.
- Do not commit, push, or modify protected refs.
